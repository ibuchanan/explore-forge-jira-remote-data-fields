# Sample form fields

These generalized labels are examples for a customer-facing form. They keep the kinds of information a form may collect while omitting customer-specific acronyms, internal naming, and duplicate variants from the source list. They are field names only; no customer-specific option values are included.

## Core

Fields that can appear across forms, regardless of subtype:

- Customer
- Request type
- Type

## Context

Fields that may appear for particular request subtypes:

- Access permissions
- Channel
- Country
- Country access
- Country removal
- Customer category
- Data input
- Data output
- Data processing
- Distributor
- Escalation origin
- Feature
- Headquarters
- Load reason
- Organizational unit
- Period
- Periodicity
- Preventive measures
- Product
- Project
- Region
- Retail customer
- Role
- Root-cause analysis
- Workspace

Several source labels were variants of the same general concept, so they are represented once here (for example, project, channel, product, and type). Labels have been translated into plain language rather than preserving customer-specific abbreviations or internal terminology.
